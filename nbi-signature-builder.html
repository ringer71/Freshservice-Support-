Classic Outlook
  1. Close Outlook.
  2. Open this folder in File Explorer:
    %APPDATA%\Microsoft\Signatures
  3. Delete every old NBI signature item: NBI Standard.htm, .rtf, .txt and the NBI Standard_files folder.
  4. Move the downloaded NBI Standard.htm into the folder.
  5. Open Outlook → File → Options → Mail → Signatures → select NBI Standard as default for new messages and replies.
New Outlook / Outlook on the web
  1. Settings → Accounts → Signatures → delete the old NBI signature.
  2. Create new, click in the editor, paste (Ctrl+V), save, set as default.
Don't edit the signature afterwards in Outlook's editor — rebuild it here instead. Editing it there is how the extra wrapper code creeps back in.
